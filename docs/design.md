# 设计约定

已确认方案：左侧导航、顶部四项统计、中间离线事项表格、右侧 Facebook 链接监控、底部渠道状态。黑白配色按用户最新要求覆盖原图绿色主色；品牌图标保持 WhatsApp 绿和 Facebook 蓝，紧急程度使用红黄绿。

侧栏 220px，桌面内容边距 28px；白色背景，#fafafa 工作区，#171717 主色，#e8e8e8 边框；主标题 28px，正文 14px，小字 12px；圆角 12px，控件 8px；过渡 160ms，遵守 reduced-motion。

页面按 dashboard / inquiries / facebook 拆分，app 只负责导航、共享数据与布局。演示数据必须明确标识；真实渠道未连接不得显示在线、虚构二维码或监控成功。真实无数据时使用空状态。
